# PetShop Amigo Fiel - Fase 1

Projeto desenvolvido para a disciplina Fundamentos de Sistemas Web, do curso de Análise e Desenvolvimento de Sistemas (ADS).

## Sobre o projeto

O projeto é um site para o petshop Amigo Fiel, formado por quatro páginas HTML ligadas por um menu de navegação.

A página inicial apresenta o petshop. A página de produtos mostra itens divididos em três categorias: acessórios, rações não perecíveis e produtos de higiene e limpeza. A página de serviços apresenta as opções de banho e tosa, com ou sem tele-busca. A última página é destinada ao contato e possui um formulário.

## Tecnologias utilizadas

O site foi desenvolvido somente com HTML5. Não foram utilizados CSS, Bootstrap ou JavaScript.

As páginas foram separadas de acordo com seu conteúdo. Também foram utilizadas tags semânticas do HTML, como `<header>`, `<nav>`, `<main>`, `<section>` e `<footer>`.

As informações dos produtos e serviços foram organizadas em tabelas. Para as imagens, foi utilizado o serviço `placehold.co`, que carrega imagens de exemplo pela internet.

## Como executar

1. Baixe os arquivos do projeto.
2. Mantenha todos os arquivos na mesma pasta.
3. Abra o arquivo `index.html` em um navegador.
4. Utilize o menu para acessar as outras páginas.

É necessário estar conectado à internet para carregar as imagens.
